how this works

The model generates one token at a time. Each token walks the pipeline in the middle column from top to bottom, and you can halt it anywhere along the way.

controls

▶ start
Runs from the beginning. Clears anything generated before.
⇥ continue
Runs until the next breakpoint fires, or until generation finishes.
↴ step
Advances exactly one stage — one node in the graph. shift-click for ten.
■ stop
Aborts the run. Everything captured so far stays inspectable.

There is no step-into or step-over: a stage is the smallest unit of execution, so there is nothing nested to step into. To skip ahead, hover any node and press ▸| to run straight to it.

breakpoints

Click the gutter or any node to set one. The eight marks inside each attention cell are that layer's heads, shaded by how focused they are right now — click one to inspect it.
